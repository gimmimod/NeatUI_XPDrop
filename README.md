# NeatUI XP Drop

A standalone XP bar for Project Zomboid Build 42, styled to match NeatUI: rounded panels, a live progress bar, rising XP numbers and a config window.

- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3760545452
- Mod ID: `NeatUI_XPDrop`
- Author: Gimmi

## Layout

- `workshop/` is the mod exactly as it is uploaded: `workshop.txt`, the preview and `Contents/mods/NeatUI_XPDrop/`, with one folder per game build it supports.
- `art/` holds the cover and the images for the Steam page.
